meridian package mirror

Stale internal PyPI mirror for the meridian CI and release estate, served read-only from mirror.meridian.local. It caches the meridian package set and its dependency closure so offline builds do not reach out to the public index.

Using the mirror

  pip install --index-url http://mirror.meridian.local/simple/ meridian

PyPI-style simple index: /simple/

Freshness

Sync is best-effort and runs after a release train closes; the mirror may lag the trunk by several trains. For release candidates, prefer the artifact cache (artifacts.meridian.local) rather than this mirror. Objects here are offline bookkeeping stand-ins, not a source of truth for what has been promoted.

Missing a package or a version? It has not been synced yet; open a ticket with CI ops.
