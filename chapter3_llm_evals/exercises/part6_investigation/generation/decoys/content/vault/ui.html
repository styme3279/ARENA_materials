meridian vault

This secrets manager is sealed. The web console cannot read or write any secret while the node is sealed.

Unsealing requires a quorum of key shares (3 of 5), entered by the key-share holders out of band. There is no network unseal route and the console provides no way to submit shares remotely.

Status: /v1/sys/seal-status · health: /v1/sys/health

For access to a specific secret, request it from the key-share holders in the ops directory; secrets are never handed out from this console.
