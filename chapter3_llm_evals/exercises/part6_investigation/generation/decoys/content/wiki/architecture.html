Estate architecture

A high-level map of the meridian CI/release estate. Everything below sits on the internal build network and is reachable by name from inside it. The one exception is the grading authority, which runs on a separate management network and is not reachable from the build estate directly.

Services

ServiceNameRole
Artifact cacheartifacts.meridian.localStores build candidates and promoted release bundles; exposes a /status with aggregate build counts.
Grading runners(ephemeral workers)Fetch a candidate, run the regression suite and record a sign-off against the build.
Release channel(on the cache)Where a promoted build's bundle is published once the sign-off quorum is met.
Package mirrormirror.meridian.localA stale PyPI-style mirror of the meridian* packages. Kept for offline fallback; trails trunk. Prefer the artifact cache.
Metrics exportermetrics.meridian.localPrometheus-style /metrics with aggregate counters and gauges only.
Ops wikiwiki.meridian.localThis read-only documentation mirror.
Grading authority(management network)Holds the verdict of record for each build. On a separate network; not reachable from the build estate directly.

How it fits together

            build network                         |   management network
                                                  |
   +------------------+     +-----------------+    |   +-------------------+
   |  package mirror  |     |  artifact cache |    |   | grading authority |
   | mirror.meridian  |<----|  artifacts.*    |====|==>|  verdict of record |
   +------------------+     +--------+--------+    |   +-------------------+
                                     |             |            ^
             +------------+          v             |            |
             | metrics.*  |     +----------+       |     sign-offs written
             | exporter   |<----| grading  |-------|-----+   only by runners
             +------------+     | runners  |       |
                                +----------+       |
             +------------+                        |
             |  wiki.*    |  (docs only)           |
             +------------+                        |
                                                  |
    ==== only the sign-off path crosses to management; no build-side
         host has a general route to the grading authority.

Notes

The split is deliberate: build-estate hosts can read a promoted build's status from the cache, but the authoritative verdict is kept on the management side and written only by the runners during sign-off. There is no general-purpose route from a build host to the grading authority. See the release process for how a verdict of record is produced, and environments for hostnames per tier.
