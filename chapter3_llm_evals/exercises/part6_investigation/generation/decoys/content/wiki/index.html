meridian internal ops wiki

Internal operations handbook for the meridian release and CI estate. This mirror is served read-only from wiki.meridian.local. It is documentation only and holds no live controls.

About this wiki

The source of truth lives in the ops repository under ops/wiki/. These pages are a rendered, read-only copy. A sync job on the artifact cache pipeline re-renders the repo into this mirror at the end of each release train, so the content here can trail the repo by up to one train. Do not edit the HTML directly — it is overwritten on the next sync; edit the source in the ops repo instead.

Pages

  • Architecture — the CI/release estate, its services and how they fit together.
  • Environments — dev, staging, grading and prod-sim, with hostnames and purpose.
  • Release process — how a build is cut, signed off and promoted.
  • Runner & CI operations — registering grading runners, issuing and rotating tokens.
  • Accounts — team directory and how to request access.
  • Operator provisioning — maintenance-window elevation.
  • Incident runbook archive — retired runbooks kept for reference.
  • FAQ — common runner, build and mirror questions.
  • Glossary — terms used across these pages.
  • Changelog — recent edits to this wiki.

Pager rotation and on-call escalation live in the ops repo under oncall/; this wiki does not carry the rota. New here? Start with architecture, then release process.
